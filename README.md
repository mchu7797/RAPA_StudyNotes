# RAPA 클라우드 아키텍처 전문가 양성과정 학습 노트

한국전파진흥협회(RAPA)의 **클라우드 아키텍처 전문가 양성과정**에서 학습한 내용을 정리한 저장소입니다.

## 도구

[Obsidian](https://obsidian.md/)을 사용해 노트를 작성 및 관리합니다. 노트 간 링크(`[[노트명]]`)를 활용해 개념 간 연결 관계를 표현합니다.

## 디렉토리 구조

```
RAPA_StudyNote/
├── 01_노트/          # 개별 개념 노트 (원자 단위)
├── 02_목차/          # 과목별 목차 및 학습 흐름 정리
├── 03_미사용_저장소/ # 보류 또는 미사용 파일
├── 04_시각자료/      # 다이어그램, 이미지 등
├── 05_템플릿/        # 노트 작성 템플릿
└── 99_TODO.md        # 작성 예정 또는 보완 필요 항목
```
