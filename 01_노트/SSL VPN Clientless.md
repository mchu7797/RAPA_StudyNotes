# 개념
Clientless SSL VPN은 웹 브라우저만으로 사내 리소스에 접속하는 SSL VPN 방식이다.

# 핵심 포인트
- 별도 VPN 클라이언트 설치 없이 빠르게 접속할 수 있다.
- 웹 기반 업무 시스템 접근에 특히 유리하다.
- 전체 네트워크 터널링보다는 애플리케이션 접근 게이트웨이 성격이 강하다.
