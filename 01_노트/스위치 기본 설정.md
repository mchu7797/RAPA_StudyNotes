# 개념
Cisco 스위치 초기 설정 절차. 호스트명, 패스워드, 원격 접근, 관리 IP 설정 순으로 구성된다.

# 핵심 포인트
- **Step 1. 호스트명 설정**: `hostname SW1`
- **Step 2. Enable 패스워드**: `enable secret cisco` (MD5 암호화 저장)
- **Step 3. 원격 접근 패스워드 설정**
  - VTY (Telnet/SSH): `line vty 0 15` → `password cisco` → `login` → `logging synchronous` → `exec-timeout 1 0`
  - Console: `line con 0` → `password cisco` → `login` → `logging synchronous` → `exec-timeout 1 0`
- **Step 4. 패스워드 암호화**: `service password-encryption` (Type 7, 약한 암호화)
- **Step 5. 배너 메시지**: `banner motd #Authorized Access Only#`
- **Step 6. 관리 IP 설정** (SVI 방식)
  ```
  interface vlan1
  ip address 192.168.1.1 255.255.255.0
  no shutdown
  ip default-gateway 192.168.1.254
  ```
- **추가 유용 설정**
  - DNS 조회 중지: `no ip domain-lookup`
  - 로그 타임스탬프: `service timestamps log datetime msec`
  - 장비 정보 확인: `show version`
  - 부팅 이미지 변경: TFTP로 복사 후 `boot system flash:/이미지명`

새 스위치를 개통할 때의 기본 설정 순서. 이름 짓기 → 자물쇠 달기(패스워드) → 원격 접근 허용 → 관리 주소 부여.
