# 개념
IPsec Tunnel Mode는 원본 IP 패킷 전체를 보호하고, 외부 전송용 새 IP 헤더를 추가하는 방식이다.

# 핵심 포인트
- VPN 게이트웨이 간 Site-to-Site 연결에 가장 일반적으로 사용된다.
- 내부 주소 은닉과 보안 경계 분리에 유리하다.
