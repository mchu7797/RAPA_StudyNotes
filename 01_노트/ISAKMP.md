# 개념
ISAKMP는 IPsec에서 보안 연관(SA) 생성/관리 절차를 정의하는 키 관리 프레임워크다.

# 핵심 포인트
- 어떤 알고리즘/정책으로 통신할지 협상 구조를 제공한다.
- IKE와 함께 동작해 실제 키 교환 및 인증 흐름을 완성한다.
