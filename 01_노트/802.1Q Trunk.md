# 개념
스위치 간에 여러 VLAN 트래픽을 하나의 링크로 전달하기 위한 프로토콜. 이더넷 프레임에 VLAN ID 태그(4byte)를 삽입한다.

# 핵심 포인트
- 일반 이더넷 프레임은 VLAN 구분 불가 → 802.1Q로 프레임에 **4byte TAG 삽입** → VLAN ID 식별
- TAG 삽입 위치: 이더넷 프레임의 Src MAC과 Ether Type 사이
- **Trunk 설정**:
  ```
  SW(config-if)#switchport trunk encapsulation dot1q
  SW(config-if)#switchport mode trunk
  ```
- **Native VLAN**: Trunk 링크에서 태그 없는(Untagged) 프레임을 처리하는 VLAN (기본: VLAN 1)
  - Native VLAN 트래픽은 TAG가 붙지 않음 (일반 이더넷 프레임과 동일)
  - 양쪽 스위치의 Native VLAN을 일치시켜야 함
- `show interfaces fa0/x trunk`: Trunk 동작 상태, 허용 VLAN 목록 확인
- `show vlan`은 Access 포트만 표시 → Trunk 포트 확인은 `show interfaces trunk` 사용

# 나만의 언어로
<!-- 이 개념을 누군가에게 설명한다면? 비유, 요약, 한 줄 정리 등 -->
여러 VLAN을 하나의 케이블로 전달할 때, 각 프레임에 "이건 VLAN 50 꺼야"라는 이름표(TAG)를 붙이는 것이 802.1Q. Native VLAN은 이름표 없이 그냥 보내는 특별 VLAN.
