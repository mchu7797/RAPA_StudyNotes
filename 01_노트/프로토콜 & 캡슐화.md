# 개념
프로토콜은 네트워크에서 데이터 전송 시 필요한 규칙과 약속. 캡슐화는 데이터를 전송하기 위해 각 계층이 헤더를 붙여 패키징하는 과정이다.

# 핵심 포인트
- **프로토콜 정의 항목**: Message Encoding / Formatting & Encapsulation / Size / Timing / Delivery Options
- **캡슐화(Encapsulation)**: 송신 측에서 상위 계층 → 하위 계층 순서로 헤더를 붙이는 과정
- **역캡슐화(Decapsulation)**: 수신 측에서 하위 계층 → 상위 계층 순서로 헤더를 제거하는 과정
- **PDU (Protocol Data Unit)**: 각 계층에서 캡슐화된 데이터 단위 명칭
  - 4계층(Transport): **Segment** | 3계층(Network): **Packet** | 2계층(Data Link): **Frame** | 1계층(Physical): **Bit**
- **Message Size**: 긴 메시지를 작은 조각으로 분할 전달, 수신 측에서 재조립
- **Message Delivery Options**
  - **Unicast** (1:1): 특정 목적지 한 곳에만 전달, 가장 일반적
  - **Multicast** (1:N): 수신을 원하는 특정 그룹에만 전달 (스위치·라우터 기능 지원 필요)
  - **Broadcast** (1:All): 동일 LAN의 모든 장비에 전달 (Dest MAC = FF:FF:FF:FF:FF:FF), 라우터에서 차단

편지 보내기와 같다. 내용(데이터)을 봉투에 넣고(캡슐화), 각 계층이 주소와 정보를 추가한다. 받는 쪽은 봉투를 순서대로 개봉(역캡슐화)한다.
