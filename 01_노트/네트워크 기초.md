# 개념
네트워크는 정보 공유를 목적으로 PC들이 연결되어 형성된 망. 효율적인 데이터 전송을 위해 규칙(프로토콜)이 반드시 필요하다.

# 핵심 포인트
- **Host (End-Device)**: 네트워크에 연결되어 통신에 직접 참여하는 모든 컴퓨터 (IP 할당됨)
  - **Server**: 서비스를 제공하는 컴퓨터
  - **Client**: 서비스를 제공받는 컴퓨터
- **LAN (Local Area Network)**: 가정, 학교, 소규모 사무실 등 제한된 영역의 Host 상호 연결
  - 스위치(Switch)가 대표 전송 장비, 이더넷 프로토콜 사용
- **WAN (Wide Area Network)**: 도시·국가 등 넓은 지리적 영역에 걸쳐 LAN을 상호 연결
  - 라우터(Router)가 대표 전송 장비, ISP 통해 구현
- **인터넷**: 전 세계적으로 상호 연결된 네트워크의 네트워크 (LAN + WAN 집합)
- **ISP**: Internet Service Provider, 사용자에게 인터넷 서비스를 제공하는 회사
  - 국내: KT, SKB, LGU+ / 미국: AT&T, Verizon / 일본: NTT
