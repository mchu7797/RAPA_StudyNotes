# 개념
ESP(Encapsulating Security Payload)는 IPsec에서 암호화 중심의 보안을 제공하는 프로토콜이다.

# 핵심 포인트
- 기밀성(암호화) + 무결성 + 인증을 함께 제공 가능하다.
- 실무 VPN 구성에서 AH보다 ESP가 주로 사용된다.
