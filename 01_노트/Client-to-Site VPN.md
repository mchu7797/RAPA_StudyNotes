# 개념
Client-to-Site VPN은 외부의 개별 사용자가 사내망으로 안전하게 접속하는 방식이다.

# 핵심 포인트
- 사용자 단말이 VPN 클라이언트 또는 브라우저로 터널을 형성한다.
- 재택/외부 근무 환경의 표준 원격 접속 구조다.
- 구현 기술은 크게 IPsec Remote Access와 SSL VPN으로 나뉜다.
