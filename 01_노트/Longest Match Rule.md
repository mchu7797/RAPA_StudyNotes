# 개념
라우팅 테이블에 목적지 IP와 일치하는 경로가 여러 개 있을 때, 비트 단위로 비교하여 **가장 길게(구체적으로) 일치하는 경로**를 선택하는 규칙.

# 핵심 포인트
- 라우터는 목적지 IP를 이진수로 변환 후, 라우팅 테이블의 각 prefix와 비트 단위 비교
- **가장 많은 비트가 일치하는 경로** = 가장 구체적인 경로 → 선택
- 더 긴 prefix(큰 서브넷 마스크) = 더 구체적인 경로 = 우선순위 높음
- **예시**: 목적지 `192.168.2.82`
  ```
  목적지: 11000000.10101000.00000010.01010010

  192.168.2.80/29 → 11000000.10101000.00000010.010100 00  (30bit 일치) ← 선택
  192.168.2.64/27 → 11000000.10101000.00000010.010 00000  (27bit 일치)
  192.168.2.0/24  → 11000000.10101000.00000010.0 0000000  (25bit 일치)
  ```
- **Default Route (`0.0.0.0/0`)**: 0bit 일치 → 아무것도 일치하지 않을 때 마지막으로 사용
- `show ip route [목적지 IP]`: 해당 IP에 대해 라우터가 실제로 선택하는 경로 확인
