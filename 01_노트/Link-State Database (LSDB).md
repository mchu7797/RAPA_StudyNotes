# 개념
- LSDB는 네트워크에 대한 [[OSPF]]의 전체 그림
	- 다시 말해, 토폴로지라고 부름
- LSDB를 국가 전체 지도와 비교할 수 있음.
- 모든 라우터가 지도를 가지게 되면 SPF 알고리즘을 사용해 모든 목적지까지 가는 최단 경로를 계산
	- 최적 경로는 라우팅 테이블에 등록
