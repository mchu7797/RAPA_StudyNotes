# 개념
AH(Authentication Header)는 IPsec에서 무결성과 인증을 제공하는 프로토콜이다.

# 핵심 포인트
- 데이터 **암호화(기밀성)** 는 제공하지 않는다.
- 패킷 위변조 검증 목적에 초점이 있다.
- 참고자료 기준 Cisco ASA 환경에서는 주 사용 프로토콜이 아니다.
